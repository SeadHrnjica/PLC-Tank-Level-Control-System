# PLC Tank Level Control System



Industrial PLC/HMI tank level control system developed in CODESYS using Structured Text (ST) programming language.



This project was developed as a portfolio and university automation project focused on:

\- industrial automation

\- PLC programming

\- HMI visualization

\- process simulation

\- control engineering principles

\- MATLAB/Simulink analysis



\---



\# Project Overview



The system simulates and controls the liquid level inside a storage tank using automatic and manual operating modes.



Implemented functionalities include:

\- AUTO and MANUAL operating modes

\- START / STOP / RESET logic

\- pump control logic

\- tank level simulation

\- alarm management

\- fault handling

\- thermal protection logic

\- LSHH and LSLL protection

\- industrial state machine architecture

\- HMI visualization in CODESYS



\---



\# Control Engineering Part



In addition to the PLC implementation, the project also includes:

\- mathematical modeling of the tank system

\- ON/OFF control with hysteresis

\- PID control analysis

\- MATLAB/Simulink simulations

\- comparison between ON/OFF and PID regulation



The simulations demonstrate:

\- oscillatory behavior of ON/OFF regulation

\- stabilization capabilities of PID control

\- process response characteristics
